# 📊 Analyzer — Browser-based ETL & BI Tool

**Analyzer** — это полноценный инструмент для работы с табличными данными, который работает **прямо в вашем браузере**. Забудьте про сложные скрипты и утечки данных: загружайте CSV/XLSX, очищайте их, объединяйте и стройте аналитику в один клик.

*Все вычисления происходят локально (Client-side). Данные не отправляются на сервер.*

## 🚀 Ключевые возможности (End-to-End Pipeline)

Инструмент закрывает полный цикл работы аналитика с «грязными» данными:

1. **🔗 Merge (Соединение):** 
   - Склейка N таблиц с поддержкой 4 типов JOIN (`INNER`, `LEFT`, `RIGHT`, `OUTER`).
   - Цепочное соединение, выбор базовой таблицы, автоматические суффиксы.
   - Умная статистика: подсветка дублей, поиск «потерянных» строк, анализ размножения данных (×N).

2. **🔍 Диагностика (Профилирование):** 
   - Автодетект типов данных (числа, даты, boolean, ID).
   - Поиск выбросов (правило 3σ), пустых колонок, смешанных типов.
   - Числовая статистика (медиана, std) и поиск потенциальных ключей.

3. **🧹 Очистка (ETL):** 
   - Приведение типов, переименование, удаление дубликатов.
   - Конструктор фильтров.
   - **Сохранение паттернов очистки в JSON** — настройте один раз, применяйте к новым файлам.

4. **📊 Аналитика (SQL-like Pivot):**
   - Конструктор группировок (GROUP BY) с мультиселектом.
   - **Живой SQL-предпросмотр:** вы видите, какой запрос собирает программа.
   - Фильтры `WHERE` (включая `IS NULL`).
   - Визуализация через Chart.js (группировка, топ-N).
   - **✨ AI-Инсайты:** Генерация локальных выводов (закон Парето, лидеры) и подготовка промптов для LLM.

## 🛠 Стек технологий
- **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS3.
- **Библиотеки:** SheetJS (парсинг Excel), Chart.js (визуализация).
- **Хранение:** LocalStorage API (сохранение сессий и паттернов).
- **Архитектура:** Модульная (разделение парсинга, логики мерджа, состояния и рендеринга).

## 💡 Почему это полезно?
Приложение решает боль аналитиков, которым нужно **быстро** (за пару минут) проверить гипотезу, склеить выгрузки из разных систем или найти аномалии, не разворачивая Jupyter Notebook и не нагружая удаленный сервер.

## 💻 Как запустить
1. Клонируйте репозиторий.
2. Запустите локальный сервер (например: `python3 -m http.server 8000`).
3. Перейдите по адресу `http://localhost:8000`.
